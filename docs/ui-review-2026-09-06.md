## Evidence and limits

Ghost at 390px now has a 342px article from x=24 to x=366; its 495px table scrolls within that column. The social lint decodes all 130 referenced local cards and verifies their dimensions, formats, alternatives, and OG/Twitter agreement. Structured-output checks cover 116 JSON-LD blocks and 122 Markdown alternates.

Browser coverage runs through `bun run test:making`, `bun run test:runtime`, and `bun run test:ui`. `bun run build` includes 73 unit/contract tests plus built-output lint. CI runs the new UI suite. Font tests use controlled local fixtures rather than third-party network timing.

The fullscreen keyboard hint is announced to assistive technology from the start and becomes visible only once a Tab or guard focus shows a keyboard is in play, so a pointer reader sees only the work.

Escape works inside eligible owned slide decks. Opaque or cross-origin iframe key events remain inside their guest; native dialog testing confirmed that boundary in Chromium too. The visible host hint and Tab/Shift+Tab guards provide a keyboard exit without widening sandbox permissions or restarting the embedded work.

Changed social designs have new asset URLs; old cards remain available for immutable caches. This is local implementation and verification: production deployment and actual social-platform scraper refreshes are separate. Existing unrelated TSM changes were excluded and preserved byte-for-byte.
