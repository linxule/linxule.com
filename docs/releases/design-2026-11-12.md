## Incident: first build hung on iCloud-evicted files

The first build sat for 25 minutes with Eleventy at 0% CPU. It was blocked
reading two image-cache files in `.deploy-worktree/.cache.nosync/@11ty/img/`
that iCloud had evicted to `dataless` placeholders; 71 files in the worktree's
`node_modules` were dataless too. Repair: killed the build, restored the two
cache files from the main checkout's `.cache.nosync`, ran
`~/.local/bin/nosync-deps --apply` on the worktree, and set
`com.apple.fileprovider.ignore#P` on `node_modules.nosync`
(`isExcludedFromSync = 1` confirmed). The second build ran clean.

Before the next deploy, check the worktree for dataless files first:
`find .cache.nosync node_modules.nosync -flags +dataless | head`.
A build that shows no CPU for a minute is stuck, not slow.
