- `the-jagged-frontier/waiting-room-5min.mp4`

This preserves Music Studio's `onFrame` extension, which a plain Strudel iframe does not provide. The archived HTML includes a pinned upstream source link and upstream licensing. Local adaptations add noindex, an explicit Stage button using the existing stage function, and a responsive 16:9 canvas. The original score is separately downloadable. Strudel and samples still need the network. Its original local classroom countdown is preserved.

Jagged's reviewed sandbox allows scripts, same-origin (REPL modules/storage), and downloads. EIGENPLATE permits scripts/downloads; Opus permits scripts. Video-only wrappers permit neither scripts nor same-origin.

EIGENPLATE preserves the original synthesis and simulation. Local changes fit the canvas and controls inside the site frame, add noindex and keyboard focus to the canvas, and explicitly focus it on pointer-down: the original preventDefault otherwise prevents keyboard shortcuts from receiving focus inside a nested iframe. Wrappers reserve space for the site's expand control.
